# 分析方法论

## 分析单位

- 用户：当前筛选范围内至少发送一条消息的去重匿名用户。
- Session：按入口、用户和会话联合键识别的一次对话。
- Round：一条 Dino 发言与随后一条用户回答；现有导出缺少首条 Dino 开场，因此轮次是可观测口径。
- 消息：孩子或 Dino 的单条记录；不能与 Round 混用。
- 周：北京时间周一至周日；不完整周明确标注，不用于误导性的整周环比。

## 三个入口的统一结构

HOME、EXPLORE、POST_CLASS 都按以下顺序呈现：

1. 用户量：用户概览、每日活跃趋势、每周流量对比。
2. 当前用户构成：年龄段、Level、国家/地区，支持按周查看。
3. 对话轮次：轮次总览、每周变化、分布和更细分档，支持周、Level、国家筛选。
4. 原有入口分析：保持已有主题、表达、Session/回访等内容并向下承接。

## 核心统计规则

- 用户和 Session 在各自展示范围去重；同一用户可访问多个入口，因此三个入口人数不可直接相加。
- 每周用户按当周有用户消息去重；每周消息按消息发生日归周。
- 每日/每周流量中的 Session 按导出首条消息归属；轮次页按筛选期内“有消息即纳入”，两种口径不可混加。
- 用户构成的分母包含画像缺失用户，并把缺失值明确列为未记录。
- 轮次分档互斥；当前基础档位为 ≤2、3–5、6–10、11–20、21+，未知值保留在分母并单列。

## POST_CLASS 专项

### 环节完成率

分母是筛选期内打开过 POST_CLASS 的去重用户；分子是在看板截止前至少有一条 `SPEAKING + COMPLETED` 任务记录的去重用户。国家明细可在“按打开人数”和“按完成率”之间切换排序。

### 是否围绕本课所学

课程事实来自会话创建时保存的 `knowledge_points_json`，它与 Prompt 的 `selected_content` 同源。按周、Level、课型分层抽样，人工对照完整会话，分为明确围绕课程、相关延展、明显偏离、证据不足。课程内容是聊天素材，不是必须逐项完成的任务清单。

### 学生行为分析

占比以抽样 Session 为分母，因为问题是“有多少段会话出现过该行为”；同一会话内重复表达只计一次，避免高频发言者放大结果。行为包括听不懂/不知道/不会、使用本地语或要求翻译、提前终止、拒绝当前内容、主动提问、主动扩展表达，以及从样本中稳定出现的新增类别。

支持按周、Level、国家筛选，并按占比从高到低展示。证据列表只展示命中片段，但提供完整原对话；非英文必须同时保留原文和英文翻译。

## 探索性分析边界

主题、意图、学生行为和 Bad Case 主要由规则扫描加人工抽样完成，不等同于全量语义标注。多标签占比可超过 100%。规则对隐含意义、ASR 错误、否定、多语言和指代覆盖有限，因此结论必须附分母、样本量、命中证据和限制，不把词频解释为学习效果。

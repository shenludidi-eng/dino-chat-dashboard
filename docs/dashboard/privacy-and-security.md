# 隐私与安全

本项目处理儿童对话和用户画像，默认按内部受限数据管理。私有 GitHub 仓库和共享密码只是访问控制的一部分，不代表可以上传全部原始数据。

## 禁止进入 Git 的内容

- 手机号、邮箱、昵称、头像 URL、精确生日和可直接识别用户的信息。
- 原始 `user_id`、`session_id`、数据库主键和未经遮盖的技术标识。
- 数据库、API、Vercel、GitHub 的凭证或 Cookie。
- `.env`、本地查询输出、完整生产导出和临时中间文件。

## 允许保存的内容

- 匿名整数索引和聚合统计。
- 为解释结论所需的最小化抽样证据；不展示技术标识。
- 原文和英文译文。翻译是附加说明，不能覆盖或删除原文。
- 构建、去标识化、校验和复现所需的脚本及审计摘要。

## 发布原则

1. 数据最小化：只发布实现看板问题所需的字段和证据。
2. 分层访问：原始数据留受控本地环境；Git 保存派生资产；网站再加认证。
3. 不缓存：认证层返回 `private, no-store`。
4. 可追溯：每个快照记录日期、数量和 SHA-256。
5. 可撤回：发现不当证据时，先下线/回滚，再从 Git 历史治理；仅删除当前文件并不能消除历史。

## 提交前检查

运行 `bash scripts/validate-dashboard.sh`，再人工检查 staged 文件列表、最大文件大小和所有新增 transcript。任何疑似身份数据都应停止提交并回到构建阶段处理。
